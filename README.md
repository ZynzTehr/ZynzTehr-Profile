## System Overview

This repository, `ZynzTehr-Profile`, hosts two decoupled runtime deliverables from a single Git tree alongside links to the external portfolio repository `ZynzTehr-Portfolio`:

1. **The Atelier Folio web profile in `index.html`, `src/`, and `public/`.** A Vite 8, React 19, and TypeScript 5.8 static single-page application deployed to Vercel at `https://zynz-tehr-profile.vercel.app/`. On viewports matching `min-width: 900px` and `min-height: 680px` with `prefers-reduced-motion: no-preference`, `HeroJourneyStage.tsx` pins one unified `540%` scroll stage via `ScrollTrigger` id `hero-journey-pin` across Act 00 `00-hero`, Act 01 `01-journey`, Act 02 `02-craft`, and Act 03 `03-stack` around a single shared `MonarchPlateFrame` that shrinks into an espresso mat, flips `-180deg` on its Y axis into a `#f7f1e6` cotton-rag card, and expands to `100vw x 100svh` in `#1f2e26` botanical olive before releasing into sticky Act 04 `04-portfolio` and slide-over Act 05 `05-connect`. Narrower viewports, shorter viewports, and `prefers-reduced-motion: reduce` sessions render vertical stacked sections with native scroll.
2. **GitHub README telemetry in `api/streak.js`, `profile-3d-contrib/`, and `.github/workflows/`.** Serverless and scheduled SVG generators rendered exclusively inside GitHub Markdown. `api/streak.js` serves the owner-locked Vercel streak SVG at `/api/streak?user=ZynzTehr`, while GitHub Actions update the contribution snake on the `output` branch and 3D contribution SVGs under `profile-3d-contrib/`.

## Interface

### Build-time feature flags in `vite.config.ts`

Vite inspects `public/media/` at startup and injects three boolean constants declared in `src/vite-env.d.ts`:

| Constant | Source check | Runtime effect |
| :--- | :--- | :--- |
| `__HAS_HERO_INTRO_VIDEO__` | `hero-monarch-intro.webm` or `.mp4` exists in `public/media/` | Plays the opening top-left butterfly flight once on initial load before revealing Hero typography, with immediate fallback on autoplay rejection, media error, focus, or scroll past `12px` |
| `__HAS_HERO_VIDEO__` | `hero-monarch-loop.webm` or `.mp4` exists in `public/media/` | Plays one Monarch wing-flutter pass on Page 1 to Page 2 transition with `loop={false}` and replays on pointer hover over the frame only when idle |
| `__HAS_PORTFOLIO_VIDEO__` | `portfolio-porch-loop.webm` or `.mp4` exists in `public/media/` | Plays one courtyard walk-out pass on Act 04 `IntersectionObserver` entry with `loop={false}` and replays on pointer hover over `[data-slot="portfolio-print-frame"]` only when idle |

### Anchor and keyboard navigation

* Chapter anchors `#hero` for `00-hero`, `#journey` for `01-journey`, `#craft` for `02-craft`, `#stack` for `03-stack`, `#portfolio` for `04-portfolio`, and `#connect` for `05-connect` route through `navigateToAnchor` in `src/lib/scrollEngine.ts`. On pinned desktop viewports, `#hero`, `#journey`, `#craft`, and `#stack` resolve directly to `hero-journey-pin` progress stops `0`, `0.235`, `0.535`, and `0.955`.
* Pressing `Cmd+K` or `Ctrl+K` toggles the native `<dialog>` chapter index in `MenuOverlay.tsx`; pressing `Escape` dismisses `MenuOverlay` or `ColophonSheet` and restores focus to its trigger button.

### Serverless streak endpoint at `GET /api/streak`

* **Accepted query parameters.** `user` omitted or case-insensitively equal to `"ZynzTehr"`, plus optional `hide_border` where `"true"` is the default and `"false"` renders the outer rectangle stroke.
* **Authorized response, `HTTP 200`.** Returns `image/svg+xml; charset=utf-8` with `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; sandbox`, `X-Content-Type-Options: nosniff`, and `Cache-Control: public, max-age=14400, s-maxage=14400, stale-while-revalidate=86400`.
* **Rejected `user` response, `HTTP 400`.** Any empty string, array, or non-owner `user` returns `HTTP 400` with `Cache-Control: no-store`, strict SVG CSP headers, and static SVG message `"Streak badge restricted to ZynzTehr"` without reading token environment variables or calling `fetch`.
* **Upstream failure fallback, `HTTP 200`.** Upstream timeouts after `5000ms`, non-2xx GitHub responses, or empty calendar parses where `daysMap.size === 0` return a static fallback SVG for `OWNER` with `Cache-Control: public, max-age=60, s-maxage=60` so transient GitHub errors never poison CDN caches for hours.

## Side Effects

* **Browser runtime.** The Web Profile makes zero runtime network calls to external APIs, analytics beacons, font CDNs, or databases. Clipboard access via `navigator.clipboard.writeText` runs only on explicit user click of the Copy Email button in `Act05Connect.tsx` and falls back to `window.getSelection` range selection if denied.
* **Serverless runtime in `api/streak.js`.** Reads optional Vercel environment variable `PAT_1`, `GITHUB_TOKEN`, or `TOKEN` and issues `POST https://api.github.com/graphql` or public fallback `GET https://github.com/users/ZynzTehr/contributions` with a `5000ms` abort timeout.
* **Scheduled GitHub Actions and Vercel build filter.** `.github/workflows/3d-contrib.yml` runs on cron `0 0 * * *` to write updated SVGs to `profile-3d-contrib/` on `main`, and `.github/workflows/snake.yml` runs on cron `0 */12 * * *` to push snake SVGs to branch `output`. `vercel.json` configures `ignoreCommand` with `git diff --quiet "${VERCEL_GIT_PREVIOUS_SHA:-HEAD^}" HEAD -- . ':!profile-3d-contrib' ':!README.md' ':!.github'` so commits touching only README telemetry paths skip unnecessary Vercel frontend builds while preserving immutable caching `max-age=31536000, immutable` on `/assets/*`.
